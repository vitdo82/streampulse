# StreamPulse v0.1 Roadmap — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execute phases in order; each phase ends with a verification gate before the next phase starts.

**Goal:** Implement the 9 v0.1 roadmap features designed in `docs/design/` — configuration, Kafka auth, scraper engine, storage queries/rollup, daemon mode, alert engine, DLQ module, analytics L1, and the CI health check — turning StreamPulse from a read-only TUI into a complete observability tool.

**Architecture:** Ten packages across five layers. Foundation: `config` (viper wiring) → `kafka` (auth). Data plane: `scraper` (collect) → `storage` (query/rollup) → `daemon` (`serve` command hosts everything). Consumers: `alerts`, `dlq`, `analytics`, `check` command, and the TUI. Design docs in `docs/design/` define all interfaces, metric names, schemas, and failure modes — each task cites its doc section.

**Tech Stack:** Go 1.25, kafka-go v0.4.47 (existing), viper (existing dep, currently unused), bubbletea (existing), modernc.org/sqlite (existing), `github.com/robfig/cron/v3` (new — scheduler per AGENTS.md dependency table), `github.com/prometheus/client_golang` (new — /metrics endpoint per AGENTS.md). Standard library for everything else (no new HTTP/SMTP/SASL deps; AWS SigV4 via stdlib).

```go
package config

import (
	"fmt"
	"os"
	"path/filepath"
	"strings"
	"time"

	"github.com/spf13/pflag"
	"github.com/spf13/viper"
)

// Load builds Config from defaults, optional YAML file, STREAMPULSE_* env
// vars, and flag overrides (in that precedence order).
func Load(flags *pflag.FlagSet) (*Config, error) {
	v := viper.New()
	v.SetEnvPrefix("STREAMPULSE")
	v.SetEnvKeyReplacer(strings.NewReplacer(".", "_"))
	v.AutomaticEnv()

	if path := configPath(flags); path != "" {
		v.SetConfigFile(path)
		if err := v.ReadInConfig(); err != nil {
			return nil, fmt.Errorf("read config %s: %w", path, err)
		}
	}

	if err := v.Unmarshal(DefaultConfig()); err != nil {
		return nil, fmt.Errorf("unmarshal config: %w", err)
	}
	cfg := DefaultConfig()
	if err := v.Unmarshal(cfg); err != nil {
		return nil, fmt.Errorf("unmarshal config: %w", err)
	}

	if flags != nil {
		if b, err := flags.GetStringSlice("brokers"); err == nil && flags.Changed("brokers") {
			cfg.Brokers = b
		}
	}
	if err := Validate(cfg); err != nil {
		return nil, err
	}
	return cfg, nil
}

func configPath(flags *pflag.FlagSet) string {
	if flags != nil {
		if p, err := flags.GetString("config"); err == nil && p != "" {
			return p
		}
	}
	if p := os.Getenv("STREAMPULSE_CONFIG"); p != "" {
		return p
	}
	for _, p := range []string{
		filepath.Join(os.Getenv("HOME"), ".config", "streampulse", "streampulse.yaml"),
		"/etc/streampulse/streampulse.yaml",
	} {
		if _, err := os.Stat(p); err == nil {
			return p
		}
	}
	return ""
}

// ScrapeInterval parses and bounds the scrape interval.
func (c *Config) ScrapeInterval() (time.Duration, error) {
	d, err := time.ParseDuration(c.ScrapeInterval)
	if err != nil {
		return 0, fmt.Errorf("scrape_interval %q: %w", c.ScrapeInterval, err)
	}
	if d < time.Second || d > time.Minute {
		return 0, fmt.Errorf("scrape_interval must be between 1s and 1m, got %s", d)
	}
	return d, nil
}
```

## Cross-cutting rules for all tasks

- **TDD:** failing test first (`go test ./<pkg>/ -run <Test> -v` must FAIL), then implementation, then PASS. Never skip the red state.
- **Errors:** wrap with `fmt.Errorf("context: %w", err)` (AGENTS.md). Sanitize auth material from all error/log output.
- **Commits:** one per task, message from the task. Conventional prefix (`feat:`, `fix:`, `docs:`, `test:`).
- **Gate:** `go build ./... && go vet ./... && go test -race -count=1 ./...` must pass after every task; integration tests (skip-without-broker pattern, `STREAMPULSE_TEST_BROKER`) pass with `docker compose up -d`.
- **No CGo, no new heavy deps:** only `robfig/cron/v3` and `prometheus/client_golang` are new; everything else stdlib (SMTP, HTTP, crypto, SASL building blocks).
- **Design docs are authoritative** for interfaces, metric names, schemas, and failure modes — read the cited section of `docs/design/<area>.md` before starting a task. If a doc conflicts with the codebase, flag it and resolve per the review table at the top of this plan.

PostgreSQL/ClickHouse backends, REST API + web dashboard, Kafka Connect/Streams integration, Analytics L2 (retention analysis drill-down, long-term trend forecasts), DLQ drain/archive commands (D/A hints removed in 9A).
